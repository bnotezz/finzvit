  - [x] `worker/parsers/parser_f1.py`: парсер форми S0100115 (Ф1 Баланс).
  - [x] `worker/parsers/parser_f2.py`: парсер форми S0100215 (Ф2 Звіт про фінрезультати).
  - [x] `worker/parsers/parser_f3.py`: парсер форми S0100311 (Ф3 Рух коштів).

  - [x] `worker/parsers/parser_f1_f2_ms.py`: парсер форми S0111007 (мікропідприємства).
  - [x] `worker/parsers/parser_generic.py`: універсальний парсер для приміток та додатків.
  - [x] `worker/parsers/parser_registry.py`: фабрика/реєстр парсерів за кодом форми.
