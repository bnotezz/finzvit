# FinZvit (ФінЗвіт) 🇺🇦

**FinZvit** — сучасний, швидкий та відкритий веб-переглядач фінансової звітності українських підприємств за офіційними формами (Держстат / ДПС / data.gov.ua).

Користувач вводить код **ЄДРПОУ** (8 цифр) або назву підприємства і отримує структуровану, інтерактивну звітність у вигляді таблиць з точним збереженням структури офіційних форм (Ф1 Баланс, Ф2 Звіт про фінансові результати, Ф3 Рух грошових коштів, Ф4 Власний капітал тощо).

---

## 🚀 Основні можливості

- **Ультра-швидкий пошук**: Повнотекстовий та префіксний пошук за ЄДРПОУ або назвою через Supabase PostgreSQL (без зависань мобільних пристроїв).
- **Офіційна структура звітності**: Точна відповідність нормам НП(С)БО та МСФЗ: назви рядків, коди, періоди (початок/кінець або звітний/попередній рік), динаміка зі зміною у тис. грн та %.
- **Модульні парсери та рендерери**: Окремий парсер для кожної форми на бекенді/воркері та ізольований компонент рендерингу для кожної форми на фронтенді (Astro 7 + React 19).
- **Легке та безкоштовне сховище**: Звіти зберігаються у чистому мінімізованому JSON у Cloudflare R2 (Zero Egress Fees), а клієнт завантажує дані безпосередньо з CDN.
- **Преміальний дизайн**: Dark-mode фінансовий інтерфейс у стилі сучасних фінтех-стартапів (глибокий антрацит, Geist Mono для фінансових цифр, смарагдові акценти).
- **Корисні інструменти**: Розрахунок ключових показників (KPI), експорт у CSV, підготовка до друку/збереження в PDF, копіювання посилання на компанію.

| Складова | Технології та версії | Призначення |
|---|---|---|
| **Веб-фреймворк** | **Astro 7.3.5** (Latest) | Статичний ультра-швидкий генератор та SSR для Cloudflare Pages |
| **Компоненти UI** | **React 19.3.0** + **@astrojs/react 7.0.0** | Інтерактивні острови (таби, пошуковий термінал, KPI картки) |
| **Стилізація** | **Tailwind CSS 4.3.3** + `@tailwindcss/vite` | Новітній рушій стилізації без застарілих конфігів |
| **Іконки та графіка** | **Lucide React 1.48.0** | Сучасний набір векторних іконок інтерфейсу |
| **Data Worker** | Python 3.11+, lxml, httpx, boto3, supabase-py | Потокове розпакування ZIP, дедуплікація версій, парсинг XML, розрахунок KPI, R2/Supabase |

## 🚀 Запуск проєкту локально

### 1. Веб-додаток:
```bash
cd web
npm install
npm run dev
```
Додаток доступний за адресою: `http://localhost:4321`.

### 2. Збірка для продакшену:
```bash
cd web
npm run build
```
*(Збірка займає ~1 секунду завдяки Astro 7 та Tailwind 4)*.

### 3. Запуск автоматизованих тестів та QA:
```bash
./scripts/qa.sh
```
*(Виконує 62 тести: парсинг усіх 5 форм, бухгалтерські рівності актив=пасив, розрахунок KPI з урахуванням 2350/2355, стійкість до битих даних, стиснення R2 Gzip та збірку Astro вебу без жодної помилки)*.

### 4. Data Worker (підготовка та завантаження даних):
```bash
python3 worker/run_worker.py --input sample/fin_zvit_2025_sample.zip --year 2025
```
